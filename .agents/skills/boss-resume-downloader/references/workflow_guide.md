# BOSS直聘 自动化简历下载技术实现与坐标规范

## 1. 界面坐标与色值规范 (2560x1440 全屏)

### 1.1 候选人列表区域
* **单行高度**：74 像素
* **槽位 X 坐标**：`250`
* **槽位 Y 坐标计算**：`Y = 138 + slot_index * 74` (例如 slot 0 为 138, slot 1 为 212, ..., slot 11 为 952)
* **日期列区域**：`[100:1360, 430:490]`，通过 EasyOCR 读取日期字符串。

### 1.2 右上角【附件简历】按钮
* **按钮范围**：`X: 2390 ~ 2485`, `Y: 67 ~ 104`
* **点击中心**：`X: 2435, Y: 85`
* **激活状态特征**：高亮紫蓝色背景
  * 色值特征：`B > 200` 且 `R < 160` 且 `G < 160`（典型 RGB: `115, 131, 255`）
  * 采样检测区域：`arr[70:95, 2390:2480]`，紫色像素数大于 200 判定为激活。
* **禁用/无附件状态**：浅灰粉/淡紫白色（典型 RGB: `245, 246, 255`），紫色像素数为 0。

### 1.3 预览大图弹窗与下载
* **弹窗下载图标**：`X: 1580, Y: 59` (向下箭头图标 `[↓]`)
* **弹窗关闭按钮**：`X: 1678, Y: 65` (圆形灰色 `×`)，或直接发送键盘 `Esc` 键。

### 1.4 聊天卡片下载按钮
* **特征匹配**：使用 `resources/download_btn_crop.png` 进行模板匹配，匹配区域为 `[200:1200, 500:1300]`，相似度阈值 `> 0.85`。

## 2. 防漏检重叠滑动机制 (Anti-Skipping Algorithm)

### 2.1 原跳跃原因
* Windows Electron 滚轮中，`pyautogui.scroll(-600)` 对应 5 个滚轮 Detent，单次滚动触发列表向上位移约 358 像素（即 4.84 个候选人）。
* 若单次使用 5 次 `scroll(-600)`，位移达 24.2 个候选人；若之前只扫描了 14 个，中间会有约 10 个候选人被直接越过。

### 2.2 防跳跃优化设计
* **视口扫描项数**：每批次扫描 12 项（覆盖 Y=138 到 Y=952）。
* **安全位移控制**：每批次扫描后仅执行 **2 次 `scroll(-600)`**，实际位移约 9.7 个候选人。
* **重叠缓冲区**：12 - 9.7 = 约 2.3 个候选人重叠。
* **OCR 姓名去重**：每点击一个候选人，通过右侧标题栏 `[40:85, 520:750]` 识别姓名并记录在 `visited_candidates` 集合中；重叠项被点击后在 0.05 秒内识别并跳过，既保证了 100% 无漏检，又保证了高速执行。
